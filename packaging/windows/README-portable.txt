Avero - portable version for Windows (x64)
==========================================

Avero is a lightweight, open source desktop email client.
https://github.com/LnYKLl/Avero

Run avero.exe, nothing to install. Windows 10 or 11 is required.

The executable is not signed yet: if Windows SmartScreen says
"Windows protected your PC", click "More info", then "Run anyway".

"Portable" means only that no installation is needed: Avero still keeps
its database and settings in %APPDATA%\Avero, and passwords in the
Windows Credential Manager. Notifications are shown under the name
"Windows PowerShell" in this version; the installer shows them under
"Avero".

Avero - version portable pour Windows (x64)

Lancez avero.exe, sans installation (Windows 10 ou 11).

L'exécutable n'est pas encore signé : si Windows SmartScreen affiche
« Windows a protégé votre ordinateur », cliquez sur « Informations
complémentaires », puis sur « Exécuter quand même ».

« Portable » veut seulement dire « sans installation » : Avero garde sa
base et ses réglages dans %APPDATA%\Avero et les mots de passe dans le
Gestionnaire d'identification de Windows. Les notifications s'affichent
sous le nom « Windows PowerShell » dans cette version ; avec
l'installateur, sous « Avero ».
